第一篇文章，写一下自己现阶段在用的东西吧。一个浅浅的记录，也顺便让博客先有第一篇文章。

## AI Coding

- IDE：在公司主要是在用 `Cursor`，因为公司有企业订阅。不过额度不多所以很快就用完了，所以主要功能是看代码，偶尔手写代码的时候补全还是很好用的。
- 命令行：
  - 主力：`claude code`，公司给的每天 100 🔪 额度（这点还是蛮大方的，虽然偶尔抽风还限制并发）。
  - 备用：`copilot-cli`，也是公司的订阅，目前还是按次数计费，可以写个长计划然后让它执行，可惜下个月就不行了。
  - 其他：
    - `codex`：基本上直接用 app，很偶尔会用 CLI。
    - `gemini-cli`：因为谷歌后续拉跨用得很少，最近还直接被抛弃了。
    - `opencode`：之前配合 `oh-my-opencode` 用得比较多，后面有点不喜欢太多概念以及很耗费 token，就基本没用了。
    - `kimi-cli`：之前因为公费订阅了一个月，浅浅尝试了下就没用了。
- GUI：
  - `codex`：目前主要在用的 app，UI 很好看，交互体验也很好，功能越来越全面。`GPT 5.5` 这个模型本身也很不错，但是 `Plus` 会员给的额度不是很多，所以基本上只在家里用用。
  - `claude` 桌面端：跟命令行有点割裂，竟然不共享配置和历史会话记录，基本上没怎么使用。
  - `alma`：尝鲜用过一下，感觉不是很适合我就没用了。

## AI 订阅

- AI 订阅主要是 `Claude` 的 `Pro` 会员和 `GPT` 的 `Plus` 会员，之前 `Gemini` 用的多，现在用的很少了。
- API 这边充了一些 `DeepSeek`，主要给自己写的小项目用，便宜好用。还有火山引擎协作者计划的免费 token，主要用于翻译。

## 终端与开发环境

- IDE：公司主要使用 `Cursor`，在家的话主要是 `VS Code`。尝试使用过 `Zed`，但是 UI 不习惯放弃了。
- 终端：
  - 主力：`Ghostty`，配合 `Starship` + `Catppuccin` 主题颜值拉满。加上 `zsh-autosuggestions` 和 `zsh-syntax-highlighting` 两个插件。
  - 备用：`Warp` 是之前的主力，但是东西越加越多，加上账号的 AI 功能老是莫名其妙被 ban，就慢慢不用了。现在基本上只有需要命令行编辑的时候才会用上。
- 包管理：主力使用 `Homebrew`，但是一些运行时的比如 `Node`、`pnpm` 还有 `Rust` 这些用 `mise` 管理，多版本管理非常好用，后面可能会写一篇文章介绍下。`Python` 的包管理用 `uv`。
- 其他：`Docker` 的客户端使用 `OrbStack`，`Yazi` 用于终端文件查看，`zoxide` 用于目录跳转；`chsrc` 用于源管理，`@chasel34/raindrop-cli` 给 AI 管理我的 `Raindrop` 收藏夹。

## 信息管理、阅读还有笔记

- 之前主要用 `Notion`，最近开始尝试 `Obsidian`，不过都没有记啥，脑袋空空。
- 信息流：主要使用 `Folo`，也是目前的信息来源之一。不过它收费后加的功能我不是很喜欢，原有功能不付费的话也砍了不少，加上自己现在更多是直接刷推，有点想切换到另一个平台了。
- `Raindrop`：收藏夹，不过主要拿来当稍后阅读 app，配合 CLI 使用，可以让 AI 帮忙整理。

## 科学上网

- 机场：`AmyTele`，有 `Claude` 专门的线路，至少目前没被封号。
- 软件：Mac 和 Windows 用 `clash-verge-rev`，手机上用 `clash-meta-for-android`。

## 其他工具和 app

- `Raycast`：启动器 + 剪贴板历史 + 快捷指令执行器，AI 功能基本没用过，之前用 `uTools`，但是某个版本它的剪贴板历史一直卡死，加上 UI 不如 `Raycast`，就切过来了。
- 截图：公司电脑用的 `Snipaste`，在家用的 `Shottr`，区别不是很大，感觉 `Snipaste` 更顺手一点。
- `DockDoor`：Dock 窗口预览增强，不过对我来说好像有点鸡肋。
- `Amphetamine`：防止系统睡眠，之前用 `tail` 命令，有个 app 在菜单栏方便一点，主要是 vibe coding 的时候会有长任务，需要这个防止系统睡眠。
- `CodexBar`：查看自己的订阅剩余额度。
- `CC Switch`：用来管理 AI 配置。
- `Proxifier`：网络代理规则工具，主要是让一些不走系统代理的工具强制走系统代理。
- `Bitwarden`：密码管理。
- 浏览器：公司的话还是 `Chrome`，在家的话主要是 `Dia`，UI 好看，AI 功能也还凑活。
